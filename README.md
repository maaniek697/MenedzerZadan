# 📝 Menedżer Zadań Pro (C# WPF)

Nowoczesna, lekka aplikacja desktopowa do zarządzania listą zadań, stworzona w technologii **WPF (Windows Presentation Foundation)**. Projekt kładzie nacisk na intuicyjne sterowanie klawiaturą oraz estetyczny ciemny motyw.

## ✨ Kluczowe Funkcje
* **Szybkie dodawanie:** Dodawaj zadania przyciskiem lub klawiszem `Enter`.
* **Inteligentne usuwanie:** Usuwaj tylko te zadania, które zostały oznaczone jako wykonane (klawiszem `Delete` lub przyciskiem).
* **Edycja w miejscu (Inline Editing):** Kliknij w tekst dowolnego zadania, aby je natychmiast poprawić bez otwierania dodatkowych okien.
* **Licznik postępów:** Dynamiczny pasek stanu informujący o liczbie wykonanych zadań (np. "Zrobione: 2 / 5").
* **Ciemny Motyw (Dark Mode):** Nowoczesny, minimalistyczny interfejs przyjazny dla oczu.
* **Automatyczny zapis:** Wszystkie zmiany (zadania, statusy, edycje) są trwale zapisywane w pliku `zadania.txt`.

## 🛠 Technologie
* **Język:** C# (Programowanie Obiektowe)
* **Platforma:** .NET 8.0
* **UI:** WPF + XAML (Stylizacja komponentów, szablony danych)
* **Środowisko:** JetBrains Rider
