# Menedżer Zadań (To-Do List) 📝

Prosta i intuicyjna aplikacja okienkowa (Desktop) do zarządzania codziennymi zadaniami, stworzona w języku C# z wykorzystaniem technologii WPF.

## ✨ Funkcje
* **Dodawanie zadań:** Wpisz tekst i naciśnij przycisk "Dodaj" lub po prostu użyj klawisza `Enter`.
* **Usuwanie zadań:** Zaznacz zadanie i kliknij "Usuń zaznaczone" lub użyj klawisza `Delete`.
* **Trwały zapis danych:** Aplikacja automatycznie zapisuje listę do pliku tekstowego (`zadania.txt`), dzięki czemu zadania nie znikają po zamknięciu programu.

## 🛠 Technologie
* **Język:** C#
* **Framework:** .NET 8.0
* **Interfejs:** WPF (Windows Presentation Foundation)
* **Środowisko:** JetBrains Rider
